# Code_Adventure

A Minecraft Fabric mod that adds a craftable **Code PC** where players spend XP to unlock and solve coding problems. Problems get progressively harder (and sometimes more expensive), and solving them grants achievements and rewards.

## Mod vision / planned features

- [ ] Add a craftable **Code PC** block/item that can be placed and used in-game
- [ ] Open a Code PC interface where players can browse/buy coding problems
- [ ] Require players to **pay XP levels** to unlock/purchase coding problems
- [ ] Provide a progression of coding problems that become **harder over time**
- [ ] Make some later problems **more expensive** to unlock
- [ ] Let players write and submit solutions in-game
- [ ] Validate/judge submitted solutions for correctness
- [ ] Track player progress (purchased/unlocked/completed problems)
- [ ] Grant **achievements** for solving problems and reaching milestones
- [ ] Grant **rewards** for completing problems (e.g. items, XP, or other bonuses)
- [ ] Add more problems, categories, and difficulty tiers over time
- [ ] Polish UI/UX, feedback messages, and balancing

## Current state

Some foundations are already in progress (e.g. Code PC block/menu/screen, XP-based level purchasing, basic in-game editor, and networking), but core features like solution judging, achievements, and rewards are not fully implemented yet.
